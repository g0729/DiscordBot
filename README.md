# DiscordBot

음악 기능 전용 디스코드 봇입니다.

## 기능

### 음악 채널
`음악채널`(기본값)에 유튜브 URL 또는 검색어를 입력하면 자동으로 대기열에 추가됩니다.

### 음악 컨트롤 패널

| 버튼 | 설명 |
|------|------|
| ▶️ 재생 | 일시정지된 음악을 다시 재생 |
| ⏸️ 일시정지 | 현재 재생 중인 음악을 일시정지 |
| ⏹️ 정지 | 음악 정지 후 음성 채널 퇴장 |
| ⏭️ 다음 곡 | 대기열의 다음 곡으로 넘김 |
| 🎶 대기열 | 현재 대기열 목록 조회 |
| 🔀 자동재생 | 대기열이 비었을 때 YouTube 믹스에서 추천곡을 자동 재생 (기본: ON) |

### 명령어

| 명령어 | 설명 |
|--------|------|
| `!join` / `!입장` | 음성 채널 입장 |
| `!add <URL>` | 대기열에 곡 추가 |
| `!remove <번호>` | 대기열에서 해당 번호 곡 제거 |
| `!음악채널생성` | 음악 채널 및 컨트롤 패널 생성 |
| `!금지어추가 <단어>` | 제목에 해당 단어가 포함된 곡 차단 |
| `!금지어제거 <단어>` | 금지어 제거 |
| `!금지어목록` | 현재 금지어 목록 조회 |

### 자동재생 (YouTube 믹스)

대기열이 비었을 때 `🔀 자동재생`이 ON이면, 마지막으로 재생한 곡의 YouTube 믹스에서 추천곡을 자동으로 가져와 이어서 재생합니다.
패널에서 버튼을 눌러 ON/OFF 전환 가능합니다.
